Arduino PIN 출입 신호등

4×4 키패드로 PIN을 입력하면 맞을 때 초록, 틀릴 때 빨강 LED가 켜지고 웹 대시보드에 결과가 남습니다. ISO 9241과 WCAG 2.2 AA를 목표로 설계했습니다.

대시보드 브라우저 데모보드 없이 화면 키패드로 체험합니다. 처음 PIN은 1234입니다. 서비스 옵션과 빵판 배선도고급키트로 만들 수 있는 6가지 서비스와 한 선씩 보는 배선도 소스 코드와 실행 방법펌웨어, Python 연결 프로그램, 웹 화면. 실제 보드 연결은 README를 따릅니다.

실제 보드는 PC에서 실행하는 연결 프로그램(pin_bridge.py)을 통해서만 제어합니다. 이 사이트의 데모는 같은 규칙을 브라우저 안에서 흉내 냅니다.
