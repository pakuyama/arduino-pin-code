# PIN 출입 신호등 · P03 대시보드

키패드로 PIN을 입력하면 맞을 때 초록 LED, 틀릴 때 빨강 LED가 켜집니다. 결과는 웹 대시보드에 표시됩니다. 배선은 강의 P03 회로를 그대로 씁니다.

- **브라우저 데모 (보드 없이 체험):** https://pakuyama.github.io/arduino-pin-code/web/
- **서비스 옵션과 배선도:** https://pakuyama.github.io/arduino-pin-code/planning/service-options.html

데모는 연결 프로그램과 같은 규칙을 브라우저 안에서 흉내 냅니다. 실제 보드를 제어하려면 아래 순서대로 PC에서 연결 프로그램을 실행해야 합니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `firmware/P03_PIN/` | 보드 코드. 강의 P03에서 두 가지를 바꿨습니다. 키 입력에 순번을 붙여 보내고, 0~3 키로 LED가 저절로 바뀌던 기능을 껐습니다. |
| `bridge/pin_bridge.py` | PC 연결 프로그램. COM 포트를 맡고, PIN 비교·잠금·LED 시간을 관리하며 웹 화면을 띄웁니다. |
| `web/` | 대시보드 화면 (`index.html`, `app.js`, `style.css`). `demo.js`는 GitHub Pages용 브라우저 데모입니다. |
| `planning/service-options.html` | 처음 검토한 서비스 옵션과 배선도 |

## 1. 보드에 코드 올리기

1. USB를 뺀 상태에서 P03 배선을 확인합니다. 키패드는 D2~D9, LED는 빨강 D10 · 노랑 D11 · 초록 D12입니다.
2. Arduino IDE에서 `firmware/P03_PIN/P03_PIN.ino`를 엽니다. 같은 폴더의 `pins.h`, `protocol.h`도 그대로 둡니다.
3. 보드를 Arduino Uno로 선택하고 실제 COM 포트를 고른 뒤 업로드합니다. 추가 라이브러리는 없습니다.
4. 시리얼 모니터에서 115200, 줄 끝 '새 줄'로 `1 STATUS`를 보내 봅니다. `"fw":"pin1"`이 보이면 정상입니다. 확인한 뒤 **시리얼 모니터를 닫습니다.**

## 2. 연결 프로그램 실행

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install pyserial==3.5
.\.venv\Scripts\python.exe bridge\pin_bridge.py
```

포트를 적지 않으면 COM3에 연결합니다. 포트가 바뀌면 `--serial COM4`처럼 붙여서 실행합니다. 실행한 뒤 브라우저에서 http://127.0.0.1:8000/ 을 엽니다.

보드 없이 PC에서 시험하려면 `--simulate`를 붙입니다. 화면 키패드는 실제 보드에 연결했을 때도 쓸 수 있고, 보드 키패드와 같은 규칙(실패 횟수·잠금)을 따릅니다.

## 동작 규칙

- PIN은 숫자 4~8자리이고, `#`으로 확인, `*`로 지웁니다. A~D 키는 쓰지 않습니다.
- PIN이 맞으면 초록 LED가 3초, 틀리면 빨강 LED가 3초 켜집니다.
- 3회 연속 틀리면 30초 동안 잠기고 노랑 LED가 켜집니다. 잠긴 동안 키 입력은 무시합니다.
- 처음 PIN은 `1234`입니다. 화면의 'PIN 바꾸기'에서 바꾸세요. PIN은 `bridge/pin.json`에 해시로만 저장됩니다. 이 파일을 지우면 1234로 돌아갑니다.
- 시도 기록은 화면을 연 동안만 보이고 파일로 남기지 않습니다. 입력한 숫자는 어디에도 남기지 않습니다.
- 보드 상태가 3초 넘게 오지 않으면 '응답 없음'을 표시하고 직접 조작을 막습니다. 응답이 없던 명령은 자동으로 다시 보내지 않습니다.
- 연결 프로그램은 이 PC(127.0.0.1)에서만 접속을 받습니다.

## 시험 기록

- 시뮬레이터 모드에서 다음을 확인했습니다.
  - 맞는 PIN과 틀린 PIN
  - `*` 지우기
  - 같은 키 반복(`1111`)
  - 3회 실패 후 잠금, 잠금 중 입력 무시, 잠금 중 수동 조작 거절
  - PIN 변경과 형식 검사
  - 다른 주소에서 온 요청 차단
- 실제 보드(Arduino UNO, COM3)에서 다음을 확인했습니다.
  - arduino-cli로 컴파일과 업로드 성공 (저장 공간 14%, SRAM 16%)
  - `STATUS`에 `"fw":"pin1"` 응답, `SIGNAL` 명령 ack 수신
  - 화면 키패드로 `1234#` 입력 → 초록 신호 후 3초 뒤 꺼짐
- 보드 키패드 입력과 LED 실제 발광은 눈으로 따로 확인해야 합니다. 보드 응답(ack)은 실제 발광을 측정한 것이 아닙니다.
